# budget-tracker
This repo contains the code for me local budget tracker and finance dashboard. It does not connect to bank accounts because it hoped to have the user be more interactive so they pay more attention to their budget and finances.

## Quick start

```bash
npm install
npm run seed   # optional: fabricated demo data
npm run dev    # http://127.0.0.1:5173
```

See [DEVELOPING.md](DEVELOPING.md) for the file map, testing, offline workflow and how to add features.
Everything runs locally; data lives in `data/finance.sqlite`, which is never committed.
